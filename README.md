# AI Text-to-Image Generator

A simple AI-powered text-to-image generator built using Python, Streamlit, and Stable Diffusion Turbo.

## Features

- Enter a text prompt
- Generate AI images
- Simple Streamlit interface
- Uses Stable Diffusion Turbo
- Runs on CPU

## Technologies Used

- Python
- Streamlit
- PyTorch
- Diffusers
- Transformers
- Hugging Face
- Stable Diffusion Turbo

## How to Run

Install the required packages:

pip install -r requirements.txt

Run the application:

streamlit run app.py
